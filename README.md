# DOX AI × ERP 등록 시연

DOX AI OCR 결과 Excel 파일을 ERP 구매·계약 필드에 매핑하고 검토·수정 후 등록하는 장면을 시연하는 정적 웹 애플리케이션입니다. 실제 DOX AI / ERP API는 사용하지 않습니다.

`dist`를 정적 웹 서버로 제공하면 실행됩니다. 원본 첨부파일이 초기 데이터와 다운로드 양식으로 포함되어 있습니다.

## 동작

- 항목 / 내용 / 확인 열을 찾고 원본 26개 필수 항목과 중복 항목을 검증합니다.
- XLSX/XLS 파일 선택 또는 드래그 업로드 후 현재 사업을 교체합니다.
- 원본 OCR 결과 26개 항목을 ERP 필드에 매핑하고 사업·공급업체·증빙서류·정산 탭에서 수정합니다. 원본값을 보존합니다.
- 원본이 정상이 아니거나 비어 있는 필드는 별도로 검토 완료해야 합니다. 값 수정 시 해당 필드의 검토를 해제합니다.
- 누락, 유효하지 않은 금액·날짜, 정산 합계 불일치는 등록 시연을 막습니다.
- 등록 미리보기에서 최종값과 변경 여부를 확인하고 JSON으로 내려받을 수 있습니다.
- 등록 시연은 브라우저 저장소에만 이력을 남깁니다. 실제 ERP 전표·계약번호는 발급하지 않습니다. 완료된 결과는 수정할 수 없습니다.
- 업로드와 임시 저장, 등록 완료 시 localStorage에 저장합니다. 기기·브라우저 간 공유나 서버 저장은 포함하지 않습니다.
- 샘플 다시 불러오기는 검토 상태를 초기화하며 기존 등록 이력은 유지합니다.

SheetJS 0.20.3을 로컬 에셋으로 포함합니다. Google Fonts가 연결되지 않아도 시스템 글꼴로 동작합니다.
