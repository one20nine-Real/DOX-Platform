# DOX-Platform

Fuji ERP · 구매·계약 관리

이 웹 자체가 구매·계약 정보를 등록·조회·수정하는 ERP입니다. 직접 입력과 Excel 입력은 같은 등록 양식에 값을 넣는 두 가지 방법입니다.

- 목록에서 검색, 등록 상태 및 입력 방식 필터를 사용할 수 있습니다.
- FUJIFILM 제공 로고와 Noto Sans KR 글꼴을 적용합니다. Excel로 입력한 건의 입력 방식 표기는 DOX AI 연결입니다. 실제 입력 기능은 기존 Excel 방식이며 외부 OCR API 호출을 추가하지 않습니다.
- 구매·계약 목록의 신규 등록 옆 DOX AI 연결 버튼은 수신함을 엽니다. 기존 3건과 사용자 제공 Excel 기반 수신 건 1건을 표시하고 상세 26개 항목을 조회할 수 있습니다. 승인하면 ERP에 등록하고, 반려하면 사유와 처리 상태만 저장합니다. 승인 건의 중복 등록을 막고 수신함 상태는 새로고침 후에도 유지합니다. 실제 DOX AI API 통신은 발생하지 않습니다.
- 수신함 최상단의 세금계산서 건은 TaxInvoice_D1_names_only.pdf를 첨부하고 해당 PDF 본문의 공급자·공급받는자 정보, 작성일자, 승인번호, 금액 및 6개 품목을 수신 데이터로 표시합니다. ERP에 없는 세금계산서 항목도 상세에서 볼 수 있습니다. 본문 공급자 대표자는 김도현, 공급받는자 대표자는 이서연입니다. PDF에 없는 입찰·계약·검수 정보는 비웁니다. PDF 원본 열기·다운로드를 지원하며 다른 수신 건에는 PDF를 표시하지 않습니다. 문서 버전 갱신 시 기존 수신함의 승인·반려 상태는 유지합니다.
- 화면 안내와 생성 데이터의 이름·메모·수행제안·표시용 관리번호에서 더미·샘플·시연 표현을 제거합니다. 내부 데이터 식별·추가 방지 속성은 유지하고, 첨부 PDF는 수정하지 않습니다.
- 시연용 더미 데이터는 브라우저별 최초 업데이트 시 한 번 추가합니다. 등록 완료 8건(계약금액 합계 333,300,000원)과 작성 중 2건입니다. 건명·담당자·공급업체 이름의 더미·샘플 표기는 제거하며 기존 저장 데이터에도 적용합니다. 기존 거래 정보는 유지하고 삭제·수정한 더미를 재생성하지 않습니다.
- 메인 대시보드에서 작성연도별 등록 완료 계약금액, 월별 계약금액, 공급업체별 상위 5개 금액, 업무 상태와 입력 방식, 최근 업무를 확인할 수 있습니다. 월별 금액은 등록 완료 건의 생성일을 기준으로 집계하며 지급액을 의미하지 않습니다.
- 목록과 상세에서 삭제하면 휴지통으로 이동합니다. 삭제된 건은 목록과 모든 지표에서 제외하며 휴지통에서 원래 상태로 복원할 수 있습니다. 영구 삭제 기능은 포함하지 않습니다.
- 신규 등록 시 Excel 없이 모든 필드를 직접 입력할 수 있습니다.
- 증빙서류 탭에서 PDF를 최대 5개(파일당 10MB) 첨부할 수 있습니다. PDF.js 5.6.205로 페이지 이동·확대·미리보기를 제공하며 원본 열기와 다운로드도 지원합니다. 파일 본문은 IndexedDB, 업무 건에는 첨부 메타데이터를 저장합니다. 임시 저장·등록 후 다시 열어도 같은 브라우저에서 복원됩니다. 첨부 제거는 건을 저장해야 확정됩니다.
- Excel은 첨부된 항목 / 내용 / 확인 양식을 읽어 26개 상세 입력란에 적용합니다. 확인 열은 ERP 등록 조건으로 사용하지 않습니다.
- 건명과 사업명·발주기관·공급업체·총액·공급가액·부가가치세를 필수로 검사합니다. 나머지 상세 항목은 선택입니다. 금액과 날짜 및 합계 일치를 검사합니다.
- 작성 중인 건은 임시 저장하고 이어서 작성할 수 있습니다. 등록 완료 후 상세 조회와 수정이 가능합니다.
- 입력값은 Excel로 내보낼 수 있고 같은 양식으로 다시 불러올 수 있습니다.
- 저장하지 않은 변경이 있을 때 페이지 이동 시 저장 여부를 선택합니다. 브라우저 재시작·새로고침에 대비하여 작성 중 내용을 자동 보관합니다.
- 이전 버전의 업무 건을 브라우저에서 이관하며 기존 저장 키는 삭제하지 않습니다.

현재 구현은 업무 데이터를 브라우저 localStorage, 업로드한 PDF를 IndexedDB에 저장합니다. 서버 DB·사용자 인증·여러 기기 간 공유는 포함하지 않습니다. 기존의 별도 ERP 전송·OCR 비교·시연 등록 흐름은 사용하지 않습니다.

`dist`를 정적 웹 서버로 제공하면 실행됩니다. SheetJS 0.20.3을 로컬에 포함합니다.

대시보드 집계 검증: `node tests/dashboard.cjs`

더미 데이터 검증: `node tests/demo-data.cjs`

DOX AI 수신함 승인·반려 검증: `node tests/dox-inbox.cjs`

세금계산서 수신 데이터·품목별 금액 대사 검증: `node tests/tax-invoice.cjs`
