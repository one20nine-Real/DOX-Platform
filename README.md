# DOX Finance

금융권 입찰 증빙서류 검토 및 정산을 위한 정적 웹 애플리케이션입니다.

`dist`를 정적 웹 서버로 제공하면 실행됩니다. 원본 첨부파일이 초기 데이터와 다운로드 양식으로 포함되어 있습니다.

## 동작

- 항목 / 내용 / 확인 열을 찾고 원본 26개 필수 항목과 중복 항목을 검증합니다.
- XLSX/XLS 파일 선택 또는 드래그 업로드 후 현재 사업을 교체합니다.
- 사업 요약, 원본 확인 상태, 금액 합계 비교, 서류 식별번호, 검색과 상태 필터를 제공합니다.
- 업로드는 브라우저에서 처리하며 localStorage에 저장합니다. 기기·브라우저 간 공유나 서버 저장은 포함하지 않습니다.
- 서류 번호는 실제 증빙파일 제출 여부를 뜻하지 않습니다. 정상 비율은 원본 확인 상태를 집계한 값이며 독립적인 문서 검증 결과가 아닙니다.
- 현황 내보내기는 다시 업로드할 수 있는 XLSX 파일을 생성합니다.

SheetJS 0.20.3을 로컬 에셋으로 포함합니다. Google Fonts가 연결되지 않아도 시스템 글꼴로 동작합니다.
